# Лабораторная работа №3

## Особенности проекта

* **Flexbox-компоновка:** реализовано горизонтальное адаптивное навигационное меню и выравнивание карточек «Мои релизы» в один ряд.
* **CSS Grid:** дашборд «Студийное оборудование» построен на двумерной сетке (на десктопе — 3 колонки в 2 строки).
* **Адаптивный дизайн:** с помощью медиа-запросов (`@media`) макет плавно перестраивается под планшеты (2 колонки) и мобильные экраны (1 колонка, вертикальное меню).
* **Блокировка скролла:** введен глобальный сброс `box-sizing: border-box`, гарантирующий полное отсутствие горизонтальной прокрутки на любых устройствах.
* **Семантическая разметка:** внедрены теги `<nav>` для меню, `<article>` для самостоятельных карточек и `<time datetime="...">` для годов релиза.
* **Работа с медиа:** пропорции обложек и фотографий строго контролируются современными свойствами `aspect-ratio` (1:1 и 16:9) и `object-fit: cover`.
* **Контрастность:** контрастность тёмно-синей и фиолетовой гаммы строго превышает стандарт 4.5:1.

## Запуск

Откройте файл `index.html` в браузере или перейдите по ссылке опубликованного сайта на GitHub Pages.
